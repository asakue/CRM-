# Инструкция пользователя

## Вход

1. Откройте адрес системы.
2. Введите логин и пароль. На экране входа есть кнопки быстрого входа для демо-ролей.
3. После входа интерфейс подстраивается под вашу роль.

## Разделы меню по ролям

| Раздел | Кто видит | Что делает |
|---|---|---|
| Панель | все | сводка по вашей роли |
| Пациенты / Моя карта | врач, зав., главврач, админ / пациент | поиск и карты пациентов |
| Записи | все | список приёмов, создание, смена статуса |
| Приёмы | пациент, врач, зав., главврач | медкарты приёмов |
| Анализы | пациент, врач, зав., главврач | направления и результаты |
| Назначения | пациент, врач, зав., главврач | рецепты |
| Врачи | все | справочник врачей |
| Отделения | врач, зав., главврач, админ | отделения и заведующие |
| Статистика | пациент(своя), зав., главврач, админ | графики и таблицы |
| Администрирование | админ | пользователи, роли, аудит, настройки |
| Профиль | все | смена пароля |

## Типовые задачи

**Записаться на приём (пациент)**
Записи → «Записать» → выбрать врача, дату и время → сохранить.
Отмена/подтверждение — открыть запись → сменить статус.

**Принять пациента (врач)**
Приёмы → «Новый приём» → выбрать пациента, заполнить диагноз (МКБ) →
сохранить. Связанная запись автоматически помечается «Завершён».

**Назначить и внести анализ (врач)**
Анализы → «Назначить» → выбрать пациента и тип. Затем открыть анализ →
«Результат» → ввести значение (оценка «норма/понижен/повышен» считается
автоматически по референсным границам).

**Посмотреть статистику (зав./главврач)**
Статистика → выбрать период (7/30/90 дней или год). Графики: визиты по дням,
топ диагнозов, пол, возраст, результаты анализов, активность; таблица нагрузки
врачей.

**Управление пользователями (админ)**
Администрирование → «Пользователи» → добавить/редактировать, сменить роль,
статус или пароль. Вкладка «Журнал аудита» показывает все действия с IP и временем.

## Безопасность (что важно знать)

- Данные пациентов зашифрованы (AES-256-GCM); в интерфейсе помечены значком «AES-256».
- Пароль должен быть не короче 8 символов.
- После 5 неудачных попыток вход блокируется на 15 минут.
- Смена пароля завершает все активные сессии.
- Администратор **не видит** диагнозы и содержимое приёмов — только статистику.
